# M8：P2 数据看板模块

## 1. 模块结构

```text
:app
 ├─ 依赖 :core_data
 └─ 依赖 :data_board_module

:core_data
 ├─ Word / ReviewRecord / WrongRecord
 ├─ WordDao / ReviewRecordDao / WrongRecordDao
 └─ AppDatabase（word_memory.db）

:data_board_module
 ├─ BoardMainActivity（MAIN + LAUNCHER）
 ├─ BoardViewModel
 ├─ BoardRepository
 └─ 看板 XML 页面
```

`data_board_module` 是独立 Gradle Module，但以 Android Library 形式合入主 APK。  
合并后的 Manifest 中有两个 Launcher Activity：

```text
com.example.wordmemory.MainActivity
com.example.wordmemory.board.BoardMainActivity
```

所以桌面会出现“单词记忆”和“数据看板”两个入口。两者在同一个 APK、同一个进程、同一个 UID 中运行，直接共享 `word_memory.db`。

## 2. 为什么同进程

“独立 Launcher”与“直接读 Room”要同时成立，最稳妥的方式是让看板 Activity 和主 App 在同一个 APK 中：

- 不需要 `sharedUserId`；
- 不需要复制数据库；
- 不需要 ContentProvider 跨进程 IPC；
- 直接复用 `:core_data` 的 `AppDatabase` 单例。

如果要求看板必须作为独立 APK 安装，则需要恢复 ContentProvider / signature 权限方案，不能直接打开主 App 私有数据库。

## 3. 查询统计

`BoardRepository` 使用主 App 的 DAO：

| 指标 | 查询 |
|---|---|
| 总单词数 | `SELECT COUNT(*) FROM words` |
| 今日复习数 | `COUNT(*) FROM review_records WHERE reviewed_at BETWEEN 今日起止` |
| 今日正确率 | 今日答对记录数 / 今日复习数 |
| 错题总数 | `SELECT COUNT(*) FROM wrong_records` |
| 各记忆等级 | `GROUP BY memory_level` |
| 近 7 天复习明细 | `review_records WHERE reviewed_at` 落在 7 天区间 |

今日范围按本地时区计算：今天 00:00 到明天 00:00。

## 4. 页面

- 四张统计卡片：总单词数、今日复习、今日正确率、错题总数；
- 各记忆等级分布：0–8 级，进度条 + 数量；
- MPAndroidChart 柱状图：近 7 天每日复习数量；
- MPAndroidChart 饼图：记忆等级分布（新学 / 1 级… / 熟词）；
- 图表空态：没有复习记录时柱状图显示“近 7 天还没有复习记录”；
- 加载态、无数据空态、读取失败状态 + 重试按钮。

ViewModel 负责把 `ReviewRecord` 聚合成 `BarEntry`，把等级统计转换成 `PieEntry`；页面只负责配置图表样式和刷新。

图表依赖：

```kotlin
implementation("com.github.PhilJay:MPAndroidChart:v3.1.0")
```

仓库需要加入 JitPack：

```kotlin
maven { url = uri("https://jitpack.io") }
```

## 5. 独立启动

```bash
adb shell am start -n com.example.wordmemory/com.example.wordmemory.board.BoardMainActivity
```

桌面入口名称：**数据看板**。  
`BoardMainActivity` 设置了独立 `taskAffinity`，会以独立任务打开。

## 6. 验证

```text
:app:assembleDebug               BUILD SUCCESSFUL
:app:testDebugUnitTest           BUILD SUCCESSFUL
:data_board_module:assembleDebug BUILD SUCCESSFUL
```

已验证：

- 无数据时显示“还没有学习数据”空态；
- 写入 3 个单词、3 条今日复习、2 条错题后，看板显示总数 3、今日复习 3、正确率 67%、错题 2；
- 各等级 Lv.0 / Lv.3 / Lv.8 数量正确；
- 写入近 7 天复习数据后，柱状图显示 7 天数量，饼图显示新学 / 3 级 / 熟词占比；
- 清空复习记录后，柱状图显示“近 7 天还没有复习记录”；
- 桌面 Launcher 查询到两个入口；
- 直接通过 `am start` 启动 BoardMainActivity 成功。
