# 统一页面状态与 UI 规范

## 1. 共享模块

新增 Android Library：

```text
:core_ui
```

`app` 与 `data_board_module` 都依赖它，避免每个页面各写一套加载/空/错误布局。

```text
core_ui/
├─ view_state_layout.xml
├─ StateLayout.kt
├─ ToastUtils.kt
└─ values/colors.xml、dimens.xml、strings.xml、styles
```

## 2. StateLayout

`StateLayout` 是 `FrameLayout` 子类，XML 中把业务内容放进去：

```xml
<com.example.wordmemory.core.ui.StateLayout
    android:id="@+id/stateLayout"
    android:layout_width="match_parent"
    android:layout_height="0dp"
    android:layout_weight="1">

    <androidx.recyclerview.widget.RecyclerView
        android:id="@+id/recycler"
        android:layout_width="match_parent"
        android:layout_height="match_parent" />
</com.example.wordmemory.core.ui.StateLayout>
```

四种状态：

```kotlin
stateLayout.showLoading()
stateLayout.showContent()
stateLayout.showEmpty(title, message, actionText, onAction)
stateLayout.showError(message, onRetry)
```

覆盖层包含：

- 加载圈 + 加载文案
- 空态图标、标题、说明、可选操作按钮
- 错误图标、标题、说明、重新加载按钮

## 3. 页面接入

| 页面 | 加载 | 空态 | 错误/重试 |
|---|---|---|---|
| 单词列表 | StateLayout | 空词库 + 添加第一个单词 | 数据库 Flow 异常 |
| 复习页 | StateLayout | 本轮复习完成 | 队列加载异常 |
| 错题本 | StateLayout | 还没有错题 | 错题查询异常 |
| 错题详情 | StateLayout | 错题记录不存在 | 详情查询异常 |
| 数据看板 | StateLayout | 还没有学习数据 | 看板查询异常 |

所有错误重试都回到各自的 `ViewModel.retry()` / `refreshQueue()` / `refresh()`，重新订阅或查询数据。

## 4. Toast 与样式

统一 Toast：

```kotlin
ToastUtils.show(context, message)
ToastUtils.show(context, R.string.xxx)
```

内部固定使用应用 Context 和 `Toast.LENGTH_SHORT`，避免页面直接写 Toast 造成样式不一致或持有 Activity。

共享样式资源：

- `@dimen/core_ui_page_padding`
- `@dimen/core_ui_page_padding_bottom`
- `@dimen/core_ui_section_gap`
- `@style/TextAppearance.CoreUi.PageTitle`
- `@style/TextAppearance.CoreUi.PageSubtitle`
- `@style/TextAppearance.CoreUi.SectionTitle`
- `@style/TextAppearance.CoreUi.Body`
- `@style/TextAppearance.CoreUi.Caption`

页面标题、StateLayout 文案、页面边距统一使用这些资源。

## 5. ViewModel 生命周期

- 所有异步操作使用 `viewModelScope`
- Flow 使用 `launchIn(viewModelScope)`
- 重试重新订阅 Flow，不持有 Fragment/Activity
- ViewModel 只持有 Repository、DAO、Application Context 等长生命周期对象
- Toast 使用 `context.applicationContext`
- 图片生成使用 `viewLifecycleOwner.lifecycleScope`，页面销毁自动取消
