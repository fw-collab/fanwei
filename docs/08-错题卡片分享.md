# 自选功能：错题卡片图片分享

## 1. 功能入口

错题本 → 错题详情 → “分享错题卡片”。

输入一条 `WrongWordItem`，生成 1080×1350 PNG 卡片，内容包括：

- 英文单词
- 音标
- 中文释义
- 累计答错次数

## 2. Bitmap 生成

`WrongCardGenerator` 使用 `Canvas` 直接绘制，不依赖页面布局：

```text
1080 × 1350 ARGB_8888 Bitmap
├─ 浅蓝背景
├─ 白色圆角卡片
├─ 橙色短装饰线 + MISTAKE CARD
├─ 错题复盘标题
├─ 蓝色单词 + 音标
├─ 分隔线
├─ 释义标签 + StaticLayout 多行释义
├─ 浅蓝统计块：累计答错 N 次
└─ 底部口号
```

配色：

```text
蓝色 #1F5FBF
橙色 #F28A2E
背景 #F5F7FC
正文 #172033
```

没有使用绿色。

## 3. FileProvider

Manifest：

```xml
<provider
    android:name=".ui.wrongbook.WrongCardFileProvider"
    android:authorities="${applicationId}.fileprovider"
    android:exported="false"
    android:grantUriPermissions="true">
    <meta-data
        android:name="android.support.FILE_PROVIDER_PATHS"
        android:resource="@xml/file_paths" />
</provider>
```

`res/xml/file_paths.xml`：

```xml
<paths>
    <cache-path name="wrong_cards" path="wrong_cards/" />
</paths>
```

保存路径：

```text
cache/wrong_cards/wrong_card_{wordId}_{timestamp}.png
```

`WrongCardFileProvider` 继承 `FileProvider`，使用独立 Provider 类，避免和看板 CSV 导出的 FileProvider 在 Manifest 合并时冲突。

## 4. 系统分享

```kotlin
Intent(Intent.ACTION_SEND).apply {
    type = "image/png"
    putExtra(Intent.EXTRA_STREAM, uri)
    clipData = ClipData.newRawUri("wrong_card", uri)
    addFlags(Intent.FLAG_GRANT_READ_URI_PERMISSION)
}
startActivity(Intent.createChooser(sendIntent, "分享错题卡片"))
```

- 用 `ClipData` 显式授予读权限
- 分享前按钮显示“正在生成卡片…”
- 生成和写文件在 `Dispatchers.Default` / `Dispatchers.IO` 执行
- 系统没有可分享应用时 Toast 提示
- Bitmap、文件、Intent 异常都会捕获并提示“分享失败，请重试”

## 5. 验证

已验证：

- 错题详情页显示“分享错题卡片”按钮
- 点击后生成 PNG，文件约 66 KB，分辨率 1080×1350
- 图片包含 `abandon`、音标、释义、`2 次`
- 系统分享面板正常弹出，可分享到蓝牙、Drive、Gmail 等
- FileProvider URI 可被分享目标读取
- 没有申请存储权限
